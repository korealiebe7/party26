# 산들 360° 룩북

`index.html`을 브라우저에서 열면 산들 코어, 샌드 카고, 소프트 뉴트럴의 세 착장을 볼 수 있습니다. 폴더 단위로 복사하면 사진과 영상이 함께 이동합니다.

## 보는 방법

1. 착장을 고르고 모델 화면을 좌우로 밀어 다른 각도를 봅니다. 화면에 키보드 초점을 두고 방향키를 눌러도 각도를 바꿀 수 있습니다.
2. **재생**을 누르면 영상이 반복됩니다. **구성 사진**으로 전환하면 옷과 소품이 한 장에 펼쳐집니다.
3. **이 착장의 제품 보기**를 누르면 구성 제품이 표시됩니다. 제품 카드를 누르면 사진이 확대됩니다.

로컬 서버를 사용하려면 이 폴더에서 PowerShell로 `python -m http.server 4173 --bind 127.0.0.1`을 실행하고 브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 제품 사양

| 항목 | 구현 |
| --- | --- |
| 사용자와 목적 | 모바일 방문자가 세 착장의 실루엣, 색 조합, 구성 제품을 확인 |
| 입력 | `01_01.png` · `01_02.mp4`, `02_01.png` · `02_02.mp4`, `03_01.jpg` · `03_02.mp4` |
| 구조 | 정적 HTML/CSS/JS, 착장 배열 한 곳에서 사진·영상·텍스트·카드를 관리 |
| 화면 | 모바일은 영상, 착장 목록, 설명, 하단 제품 버튼 순서. 넓은 화면은 영상과 착장 정보를 나란히 배치 |
| 제품 | 착장별 5개, 3개, 5개. 사진에서 확인되는 의류와 소품의 색상·형태를 설명하고, 카드는 해당 사진을 확대 |
| 재생 | 720×1280 H.264, 24fps, 6프레임마다 독립적으로 탐색 가능한 프레임 삽입. 사용자가 재생을 누르면 반복 |
| 접근성 | 키보드 탐색, 초점 표시, 제품 창 닫은 뒤 초점 복귀, 기기의 모션 감소 설정 반영. 전환음은 기본 꺼짐 |
| 오류 처리 | 영상 로드에 실패하면 해당 착장의 구성 사진, 안내 문구, 다시 시도 버튼 표시 |
| 데이터와 비용 | 파일을 브라우저에서 읽어 표시. 로그인, 외부 API 호출, 방문 데이터 수집 없이 작동 |
| 공개 조건 | 사진·영상의 공개 사용 권한과 실제 판매 정보를 확인한 뒤 공개. 판매 주소가 제공되면 카드에 연결 가능 |

## 폴더 구성

- `index.html` · `lookbook.css` · `lookbook.js` — 화면, 스타일, 착장 데이터와 조작
- `assets/` — 세 착장의 탐색용 MP4, 영상 첫 화면, 구성 사진
- `assets/products/` — 제공 사진에서 자른 제품 이미지 13장
